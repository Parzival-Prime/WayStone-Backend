# Some things in WayStone

### Custom username pattern

##### ✅ Valid examples
- execute-spell(Parzival)
- execute-spell(Parzival Prime)
- execute-spell(Parzival.Prime)
- execute-spell(Parzival-Prime)
- execute-spell(Parzival_Prime)
- execute-spell(Parzival-Prime_rt)

##### ❌ Invalid examples
- execute-spell( Parzival)     // leading space
- execute-spell(Parzival )     // trailing space
- execute-spell(Parzival123)   // digits
- execute-spell(Parzival..A)   // >2 symbols
- execute-spell(Parzival__A)   // >2 symbols
- execute-spell(Parzival--A)   // >2 symbols
- execute-spell(Parzival-)     // trailing symbol
